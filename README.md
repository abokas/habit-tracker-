# ÉLAN — Habit Tracker

Файлы разделены:
- index.html — структура страницы
- style.css — весь дизайн и анимации
- script.js — интерактивность, привычки, календарь, аналитика и RU/EN

## Запуск
Откройте `index.html` в браузере.

## Возможности
- RU / EN переключение
- сохранение привычек через localStorage
- отметка выполнения и streak
- добавление новых привычек
- календарь активности
- аналитика с анимированными столбцами
- responsive layout
- luxury/minimal дизайн
- Cormorant Garamond + DM Sans
- micro-interactions и cursor glow
